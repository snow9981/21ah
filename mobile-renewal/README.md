# 스물하나 동물병원 모바일 중심 개편

작성일: 2026-10-24

기존 홈페이지를 변경하지 않고 새 디자인을 개발하는 작업폴더입니다.
모바일 중심 1차 시안 구현 완료. 기존 공개 홈페이지는 변경하지 않았습니다.

## 폴더

- `reference/`: 기존 HTML, CSS, JavaScript 및 이미지의 참고용 사본. 새 홈페이지 배포 대상이 아닙니다.
- `site/`: 독립 실행 가능한 정적 홈페이지. index.html, 진료별 상세 페이지 4개, 비용 문의 페이지.
- `incoming/`: 추후 제공할 사진과 사용 허락을 받은 리뷰 자료.

기존 Git 저장소 안에 있는 폴더이므로 독립 저장소가 아닙니다. 추후 배포는 참고자료를 제외하고 `site/`만 대상으로 설정해야 합니다.

## 첫 페이지 구성안

모바일 유입 90% 이상을 가정합니다. 작은 화면부터 설계하고 PC로 확장합니다.

1. 간결한 상단: 로고, 병원명, 메뉴 버튼.
2. 짧은 대표 영역: 실제 병원 사진, 병원명과 지역, 기존 슬로건. 과도하게 높은 사진이나 자동 전환 메시지는 피합니다.
3. 네 가지 핵심 진료: 건강검진 / 심장 진료·심장초음파 / 안전을 위한 스케일링 / 고양이 친화 진료. 모바일 2열 2행으로 표시하고 각 상세 안내로 연결합니다.
4. 의료진 소개: 사진, 이름, 검증된 경력과 담당 분야. 자세한 약력으로 연결합니다.
5. 네 가지 진료의 짧은 소개: 실제 사진과 구체적인 진료 과정. 상세 내용은 개별 페이지로 분리합니다.
6. 관련 사진과 보호자 후기: 진료 소개 사이 최대 1~2곳에 선택적으로 삽입합니다. 자료가 없으면 표시하지 않습니다.
7. 방문 안내: 주소, 진료시간, 전화, 주차 정보(확인 후), 지도와 길찾기.
8. 푸터: 병원 정보, 블로그·플레이스·진료비 안내 링크.

하단 고정 행동: 전화 / 길찾기 / 카카오톡. 본문을 가리지 않도록 여백과 기기 안전영역을 확보합니다.
첫 화면의 목표는 병원 정체성과 네 가지 강점의 빠른 파악입니다. 작은 기기에서 모두 억지로 넣기 위해 글자를 줄이지 않습니다.

## 확인된 콘텐츠

### 고양이 친화 진료

- 고양이 전용 진료실
- 분리된 고양이 입원장
- 한국고양이수의사회 회원 허지성 대표원장 (사용자 확인)
- 고양이를 배려하는 전 직원의 응대
- 학회 회원 이력을 병원 인증처럼 표시하지 않습니다.

### 스케일링

병원 블로그 참고: https://blog.naver.com/carepaws/224408397241

글에 소개된 과정: 마취 전 혈액검사·흉부 방사선검사, 정맥 수액, 호흡마취, 심박수·산소포화도·이산화탄소·호흡수 모니터링, 스케일링과 폴리싱, 산소 공급·보온·회복 확인, 귀가 후 관리 안내.
사례를 모든 환자에게 동일하게 적용되는 절차로 단정하지 않습니다. 검사 및 마취 계획은 상태에 따라 달라질 수 있으며 안전을 보장하는 문구는 쓰지 않습니다.

## 이미지와 리뷰

- 기존 이미지는 참고용 사본에서 실제 내용을 확인한 뒤 선별합니다. 임시 이미지나 동일한 사진의 반복 사용은 피합니다.
- 모바일용 이미지 크기와 압축을 별도로 적용합니다.
- 후기는 실제 원문과 재게시 허락을 확인하고 개인정보를 가립니다.
- 발췌 여부, 출처, 작성일, 원문 링크를 함께 관리합니다.
- 리뷰를 작은 글자의 합성 이미지로만 제공하지 않고 읽을 수 있는 텍스트를 함께 둡니다.
- 실제 자료가 오기 전 임의 후기와 별점을 생성하지 않습니다.

## 검색 및 운영 원칙

- 핵심 내용은 JavaScript 없이도 읽을 수 있는 HTML로 제공합니다.
- 진료별 독립 URL, 고유 제목·설명, 실제 canonical, 사이트맵을 준비합니다.
- 구조화 데이터는 화면에 표시한 실제 병원 정보와 일치시킵니다.
- 기존 에디터의 로컬 초안이 공개 페이지를 덮어쓰는 방식은 그대로 복제하지 않습니다.
- 네이버 블로그와 홈페이지는 서로 관련된 상세 콘텐츠로 연결합니다.
- 검색 순위나 AI 인용을 보장하지 않습니다.

## 실행과 수정

`site/index.html`은 파일로 직접 열어도 동작합니다. 로컬 검수 주소: http://127.0.0.1:8766/

- 문구와 페이지 구조: `build.cjs` 수정 후 Node.js로 실행하여 정적 HTML 생성.
- 스타일: `site/styles.css`, 동작: `site/script.js`.
- 진료비 틀: `price-content.json`의 `groups`에 분류와 항목을 관리합니다. `amount`는 표시할 금액 문자열이며, `null` 또는 빈 문자열이면 "게시 준비 중"으로 표시됩니다. `basis`에는 체중·단위·포함 항목 등 적용 기준을 적을 수 있습니다.
- `effectiveDate`는 적용일, `notes`는 공통 안내 문구입니다. 금액이 모두 확정되면 준비 중 안내가 자동으로 사라집니다. 변경 후 `build.cjs`를 실행합니다.
- 진료비는 제공된 병원 안내표와 사용자 확인에 따라 6개 분류, 23개 세부 항목을 반영했습니다. 최종 결제금액, 입원비 1일 기준, 백신·안텔민 고정금액, 혈액화학검사의 항목 수·패널별 차이를 표시합니다. 메인 진료 카드 아래 배너는 `price.html`로 직접 연결됩니다. 항목별 게시 기준 충족 여부와 가격 변경 시 갱신은 별도 확인이 필요합니다.
- 생성기는 bundled Node 패키지의 sharp와 lucide를 사용합니다. 다른 PC에서는 `CODEX_NODE_MODULES` 환경변수를 해당 패키지 위치로 지정합니다.
- 배포 시 별도 서버나 Node.js가 필요하지 않습니다. `site/` 파일만 사용합니다.
- 현재 미완성 시안이 검색되지 않도록 `noindex,nofollow`를 적용했습니다. 최종 도메인을 확정한 뒤 `SITE_URL`을 지정하여 다시 생성하면 canonical과 사이트맵, 색인 허용이 반영됩니다.
- 호스팅 루트의 robots.txt, Search Console 등록 및 실제 검색 반영은 배포 단계에서 별도로 확인합니다.
